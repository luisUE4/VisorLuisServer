
Aplicacion API para almacenar, procesar y sincronizar documentos con clientes.
Destaca la funcionalidad:
-indexado y RAG con modelos IA locales
-Busqueda hibrida semantica , precisa y por identificadores
-Embeddings para busqueda semantica y clasificacion de informacion
-seguridad HTTPS y certificados de seguridad
-Sincronizado de documentos en clientes y servidor
-Sistema de usuarios que separa almacenamiento y bases de datos y bases de datos vectoriales
-OCR con cola de procesamiento asincrona para documentos tipo imagen con tesseract

Este servidor es parte de un sistema diseñado para trabajar con dispositivos android,
la aplicacion android tambien contiene modelos IA locales que corren offline en el dispositivo movil, 
ademas de tener su propio indexado y alamacenado usando encriptacion y funciona como el visor universal 
de documentos en el dispositivo creando un sistema que permite visualizar y almacenar todo documento visualizado
usando seguridad y usando el servidor como nube de archivos donde se almacenan y procesan los documentos.
Ademas el dispositivo movil puede buscar en sus propios archivos de forma semantica o precisa y al mismo tiempo
recibir resultados de la busqueda desde el servidor , es decir el dispositivo no depende del servidor pero
el servidor aumenta las funcionalidades de la aplicacion movil.
